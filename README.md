# Georgia Drinking Water Contamination and Cancer Incidence

## Overview

This project investigates whether county-level exposure to health-based drinking water violations is associated with cancer incidence across Georgia counties.

The analysis combines publicly available datasets from the Georgia Department of Public Health and the U.S. Environmental Protection Agency (EPA) using Python to create a county-level dataset suitable for exploratory statistical analysis.

## Research Question

> Is exposure to contaminated drinking water associated with cancer incidence across Georgia counties?
